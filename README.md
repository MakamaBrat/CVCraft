# CVCraft

Мобільний веб-застосунок для створення резюме: майстер заповнення даних, портфоліо з відео/гіфками, вибір шаблону, попередній перегляд, PDF-експорт і публічне посилання на резюме. Дані користувача прив'язані до Telegram (ID + нікнейм) і зберігаються в Supabase.

## 1. Налаштування Supabase

1. Створіть проєкт на [supabase.com](https://supabase.com).
2. Відкрийте **SQL Editor → New query**, вставте вміст файлу `supabase/schema.sql` з цього репозиторію і натисніть **Run**. Це створить таблицю `resumes` і потрібні політики доступу.
3. Перейдіть у **Project Settings → API** і скопіюйте:
   - `Project URL`
   - `anon public` ключ

## 2. Локальний запуск

```bash
cp .env.example .env
# вставте свої значення VITE_SUPABASE_URL і VITE_SUPABASE_ANON_KEY у .env
npm install
npm run dev
```

Якщо змінні не вказані, застосунок автоматично працює в офлайн-режимі (дані лише в localStorage браузера, без публічних посилань).

## 3. Деплой на Vercel

1. Завантажте цю папку на GitHub.
2. На vercel.com → **Add New → Project** → оберіть репозиторій.
3. У розділі **Environment Variables** додайте:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. Натисніть **Deploy**.

## 4. Підключення як Telegram Mini App

1. У [@BotFather](https://t.me/BotFather) створіть бота (`/newbot`), якщо ще немає.
2. Команда `/newapp` → оберіть бота → вкажіть назву, опис, іконку та **URL вашого застосунку на Vercel** (наприклад `https://cvcraft.vercel.app`).
3. Готово: бот отримає кнопку/посилання, яке відкриває застосунок як Mini App прямо в Telegram.
4. При відкритті застосунок сам зчитує ID, нікнейм і ім'я користувача з Telegram — окремий вхід не потрібен. Якщо застосунок відкрито у звичайному браузері (не в Telegram), з'явиться форма ручного введення — це лише для тестування.

### Поширення конкретного резюме через бота

Кнопка "Поділитись резюме" копіює пряме посилання виду `.../#/r/<id>` — воно працює, якщо застосунок відкривається як **Web App-кнопка** з прямим URL (стандартний спосіб через `/newapp`).

Якщо ваш бот запускає застосунок через `t.me/<bot>/<app>?startapp=...`, використовуйте як startapp-параметр значення `r-<id>` (наприклад `r-a1b2c3d4-...`) — застосунок розпізнає такий параметр так само, як і посилання з `#/r/`.



- **Вхід**: усередині Telegram застосунок автоматично зчитує ваш Telegram ID, нікнейм та ім'я через Telegram Web App SDK — без пароля, без форми. Поза Telegram показується форма ручного введення (для розробки/тестування).
- **Резюме** зберігаються в таблиці `resumes` у Supabase, прив'язані до `telegram_id`.
- **Поділитись резюме**: на екрані перегляду є кнопка "Поділитись резюме" — вона копіює посилання виду `https://ваш-домен.vercel.app/#/r/<id>`. За цим посиланням будь-хто відкриває застосунок одразу з переглядом конкретного резюме, включно з відтворенням відео та гіфок з портфоліо — без входу через Telegram.
- **Тема**: застосунок повністю темний (фон `#0a0a12`, фіолетовий акцент), включно з екраном публічного перегляду.

## Стек

- React 18 + Vite
